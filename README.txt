강릉제일고 1-2 학급 다이어리 — 학생 앱 (GitHub Pages) 올리는 방법

이 폴더는 학급 다이어리 화면을 학생 휴대폰에 저장해 두고 바로 띄우는 앱입니다.
화면 파일은 처음 한 번만 받아 휴대폰에 저장되고, 자료(기록 · 공지 등)만 Apps Script와 주고받습니다.
앱 아래 탭: 클래스보드 · 21일 · 문제해결 · 소감문 · 학급회의 · 상담

■ 1단계. GitHub 저장소에 올리기
  1) 압축을 풉니다. (index.html · app.html · gas.js · config.js · sw.js · manifest.webmanifest · 아이콘 3개)
  2) 저장소(class-diary)에서 [Add file] → [Upload files]로 모두 올려 덮어쓰고 Commit 합니다.
     fonts 폴더는 그대로 둡니다. (지우지 마세요)
  3) 1~2분 뒤 https://아이디.github.io/class-diary/ 에서 첫 화면이 뜨면 성공입니다.

■ 2단계. 담임 기록실에 주소 적기
  담임 기록실 → 교실 화면 → [학생 휴대폰 · 학생 앱] → [학생 앱 주소]에 위 주소를 적고 저장합니다.
  그러면 클래스보드 공유 주소 · 첫 화면 링크 · 교실 TV 주소가 모두 빠른 주소로 바뀝니다.
  (교실 TV는 담임 기록실에서 새 TV 주소로 한 번 다시 열어 주세요.)

■ 3단계. 학생들에게 알려 주기
  - 안드로이드: 크롬으로 열기 → ⋮ → [앱 설치] 또는 [홈 화면에 추가]
  - 아이폰: 사파리로 열기 → 공유 버튼(□↑) → [홈 화면에 추가]
  - 이미 예전 앱을 설치한 학생은 그대로 써도 되지만, 지우고 다시 추가하면 아이콘 · 색이 새것으로 바뀝니다.

■ 알아 둘 점
  - 화면이나 기능을 고쳐 Apps Script를 새 버전으로 배포하면, 학생 앱은 다음에 열 때 알아서 새 화면을 받습니다. zip을 다시 올릴 필요가 없습니다.
  - Apps Script 웹앱 주소가 바뀌었을 때만(새 배포를 만든 경우) zip을 다시 받아 올려 주세요. config.js에 주소가 들어 있습니다.
  - Apps Script 배포 설정의 [액세스 권한]은 [모든 사용자]여야 합니다.
  - Apps Script 주소로 여는 예전 방식도 그대로 됩니다.
