강릉제일고 1-2 학급 다이어리 — 학생 앱 설치 방법

이 폴더는 학생들이 휴대폰 홈 화면에 설치하는 앱입니다. 앱 안에 [21일 · 문제해결 · 상담 · 클래스보드] 탭이 있습니다.
선생님이 한 번만 인터넷에 올려 두면, 학생들은 그 주소를 열어 설치하면 됩니다.

■ 1단계. 인터넷에 올리기 (둘 중 하나, 무료)

[방법 A] Netlify — 가장 쉬움
  1) 이 zip 파일의 압축을 풀어 폴더 하나로 만듭니다.
  2) netlify.com 에 무료로 가입(구글 계정 로그인 가능)합니다.
  3) Sites 화면에서 [Add new site] → [Deploy manually]를 고르고, 압축 푼 폴더를 통째로 끌어다 놓습니다.
  4) 잠시 뒤 https://○○○.netlify.app 주소가 생깁니다. Site configuration에서 이름을 바꿀 수 있습니다.

[방법 B] GitHub Pages
  1) github.com 가입 → 새 저장소(Public) 만들기
  2) [Add file] → [Upload files]로 압축 푼 파일들을 모두 올리고 Commit
  3) Settings → Pages → Branch를 main / (root)로 정하고 Save
  4) 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소가 생깁니다.

■ 2단계. 학생들에게 알려 주기
  - 위에서 생긴 주소를 학생들에게 보내 주세요. (포스터 QR 코드를 이 주소로 바꿔도 됩니다)
  - 안드로이드: 크롬으로 열기 → 오른쪽 위 ⋮ → [앱 설치] 또는 [홈 화면에 추가]
  - 아이폰: 사파리로 열기 → 아래 공유 버튼(□↑) → [홈 화면에 추가]
  - 카카오톡 안에서 열면 설치가 안 됩니다. 크롬/사파리(다른 브라우저로 열기)로 열어 주세요.

■ 알아 둘 점
  - 앱은 학급 다이어리를 탭으로 묶어 보여 주는 껍데기입니다. 기능을 고치거나 새 버전으로 배포해도 앱을 다시 올릴 필요는 없습니다.
  - 다만 담임 기록실에서 [학생용 보기 주소]를 새로 만들었거나 웹앱 주소가 바뀌었다면, 이 zip을 다시 받아 같은 곳에 다시 올려 주세요.
  - 탭을 한 번 더 빠르게 두 번 누르면 그 탭을 새로 불러옵니다.
