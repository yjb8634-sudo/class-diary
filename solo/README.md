# 클래스 나우 — 각자 설치판

학급 자료를 **선생님 본인 구글 계정(시트 · 드라이브)에만** 저장하는 판입니다. 제작자 서버가 없습니다.

| 파일 | 쓰임 |
| --- | --- |
| `클래스나우_설치판.gs` | 선생님이 복사해 가는 **설치용 한 파일** (앱.gs + core.js 를 합친 것) |
| `앱.gs` | 앱스 스크립트 쪽: 시트 저장 · 설치 화면 · 드라이브 저장 |
| `core.js` | 저장소 규칙(권한) · 요청 처리 — Node 자동 시험에서도 그대로 사용 |
| `build.py` | 위 둘을 합쳐 `클래스나우_설치판.gs` 를 만듦 |

- 권한 규칙은 `firebase/firestore.rules` 를 그대로 옮긴 것입니다. 규칙을 고치면 두 곳을 함께 고치세요.
- 화면(관리 · TV)은 GitHub Pages(`classroom/`)의 같은 파일을 쓰므로, 화면 업데이트는 선생님들이 아무것도 안 해도 반영됩니다. 이 폴더가 바뀔 때만(드물게) 다시 붙여넣기가 필요합니다.
